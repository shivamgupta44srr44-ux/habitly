# Habitly 🌱

A responsive, static habit tracker layout built as Week 1 of the CodGen Frontend Internship.

**Live demo:** https://<your-username>.github.io/habitly/

## What's inside
- Header with brand, date and intro line
- Summary row with 3 stat cards (daily progress, best streak, weekly score)
- Grid of 5 habit cards, each with an emoji, streak, 7-day activity dots and a Complete button
- Footer

## Tech used
- Semantic HTML5 (`header`, `main`, `section`, `article`, `footer`)
- CSS custom properties for colors and an 8px spacing scale
- CSS Grid with `repeat(auto-fit, minmax(240px, 1fr))` and Flexbox
- Responsive at 360px, 768px and 1280px
- Hover and focus states on cards and buttons
- Inter font (Google Fonts) with a system-font fallback

## What I learned
- Structuring a page with semantic tags
- Building a reusable card design
- Making a layout responsive with a mobile-first approach
